# macOS CPU inference memory investigation

The first eight-case hosted run of source `901c70a` failed on macOS after
90 minutes. Five cases completed; repeated 2200-pixel candidate timeouts near
180 seconds caused poorer fallback selections. The clean case selected a
74.64 µV RMSE fallback, versus Linux's 16.37 µV result. Fast contracts and Linux
passed, but supported-platform equivalence did not. The
[failed run](https://github.com/alexprotonotarios/ecg-waveparse/actions/runs/34055758855)
and its partial reports remain evidence. Raising its timeout would not resolve
that fidelity difference.

## Implementation

For macOS CPU inference, evaluate the pinned U-Nets' 3×3 replicated-edge and
2×2 downscaling convolutions in row stripes, targeting 16 MiB for each temporary
im2col matrix. Interior stripes include real neighbouring rows. Global
InstanceNorm, model weights, image resolution, float32 precision and the full
U-Net graph remain unchanged. Other convolution geometries, devices, autograd
and autocast retain their existing operators. Both segmentation and label
models are covered. Linux and MPS keep their existing execution path.

The short-lived macOS CPU inference child also starts with
`MallocLargeCache=0`. Apple's allocator supports this setting to disable its
large-allocation cache; the parent environment and other devices are unchanged.
See the [Apple allocator implementation](https://github.com/apple-oss-distributions/libmalloc/blob/main/src/malloc.c).
No native allocator API or extra dependency is added.

## Fixed-gate development comparison

One controlled clean image, one signal family, CPU with three Torch threads,
2200-pixel inference and the same pinned model weights were compared. The
original installed payload was `e84bef376703e8029ac673cfbc1f85d6cbc5fbb1db608367ca221e7e4c22150b`.
The candidate probe loaded the production convolution helper against that
verified payload and applied the child allocator setting.

| Measure | Original | Candidate |
| --- | ---: | ---: |
| Full forward | 145.75 s | 21.43 s |
| Peak process RSS | 8.74 GiB | 3.93 GiB |
| Canonical sample locations compared | 28,923 | 28,923 |

Between outputs, RMSE was 0.00055 µV, maximum logit difference was 0.0000411,
and missingness, layout and calibration spacing matched. The unchanged
0.001 µV RMSE, 0.0001 logit, zero missingness, matching layout, 0.000001 mm
spacing, 180-second and 5-GiB investigation gates all passed for this case.
RSS is macOS getrusage's process maximum, not a claim that every input fits
below 5 GiB.

[Compact experiment evidence](verification/2026-09-06-cpu-convolution.json)
retains every completed variation, including memory failures. Small scratch
buffers alone did not consistently meet the memory target. Changing model
activation lifetimes, consuming normalization buffers, requesting allocator
pressure relief and reducing CPU threads were investigated and not adopted.
The final method preserves the original model graph and normalization.

Boundary tests cover stripe seams, replicated image edges, odd downsampling,
batches, noncontiguous inputs, unchanged input tensors, fallback operators,
autograd/autocast and an actual upstream U-Net comparison. The wrapper's
platform routing is also tested. These tests are separate from real installed
inference and hosted verification.

## Hosted verification boundary

The workflow retains all eight frozen inputs and the existing quality and
platform-equivalence limits. Stages are visible separately, process-tree
resources are sampled, and partial canonical/uncertainty/segment evidence can
be retained after interruption. Incomplete evidence cannot satisfy equivalence.
Lifecycle tests reuse the completed clean run, verifying its source hash and
exercising rejection, retention, tampering, cancellation and recovery without
another full extraction.

This preparation report does not claim a successful rerun. Installed-package
regression, hosted platform results and exact delivered artifact identities
are recorded separately. The prior 25-patient final evaluation remains bound
to its original payload; its failures are retained and its exposed patients
are not reused for tuning this fix. No clinical acceptance, registry release,
model redistribution or deployment is claimed.
