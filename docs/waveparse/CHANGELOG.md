# Changelog

## 6 September 2026 — continuation, unpublished

- Printed speed/gain evidence retains alternatives, confidence, source coordinates
  and hashes. Conflicting or unsupported settings refuse quantitative output.
  Stored raster coordinates stay consistent across all EXIF orientations.
- Trusted nondefault gain now reaches the neural physical-unit normalizer,
  repeats and CPU confirmation. Consistent row-grid periods conservatively
  refine horizontal scale. Default-gain regression waveforms remain exact.
- Policy v3 names the calibration gate; numerical thresholds and selector feature
  semantics remain unchanged. Old default-gain selector priors are not applied
  to nondefault gains.
- Scorer v7 adds labelled amplitude/duration endpoints, actual-resolution
  visibility and measurement-detector error. Missing endpoints and failed
  coverage gates remain explicit.
- Actual pretrained, local-grid, two-sided-verifier and selection comparisons
  have recorded adoption decisions. No new production model, local warp,
  automatic verifier veto, model cache or persistent worker is promoted.
- The source toolchain is reduced to nine installed packages on the tested Mac.
  Its exact lock versions/integrities, runtime payload and executable interfaces
  reproduce. NodeNext declaration import queries include their required suffix.
- CI prepares shared input bytes and an aggregate platform comparison that
  fails on missing prerequisites. Current local CPU/MPS comparisons expose
  numerical/candidate-count drift and a memory-budget overrun; hosted execution
  of this candidate remains unverified.

See [the acceptance audit](ACCEPTANCE-AUDIT-2026-09-06.md) and
[continuation evidence](COMPLETION-WORK-2026-09-06.md) for exact scope and open
criteria. API compatibility does not certify numerical or clinical equivalence.

## 6 September 2026 — archived first engineering campaign

- Permanent review bundles retain compact signals, uncertainty and immutable
  segment/interval lineage. Missing legacy evidence remains explicitly unavailable.
- Physical, source-coordinate, durable-record and input validation reject
  malformed evidence consistently. Processing, reconstruction, eligibility and
  review have separate reported dimensions.
- Scoring v6 distinguishes lead-local fidelity from canonical placement and
  source-label identity, including canonical truth/uncertainty coordinates.
  All-attempt and grouped evaluation preserve abstentions and missing results.
- Both installed interfaces expose local source/segment evidence on returned
  signals and abstentions. CI runs an unfiltered fast tier and native package
  matrix; a pinned non-root Linux recipe and executable examples are included.
- The frozen eight-case regression preserves every returned waveform exactly.
  A separate 16-group public pilot returned 12 signals but only six met fixed
  engineering qualification gates. Experimental decoders/warps were not promoted.

See [ENGINEERING-IMPROVEMENTS.md](ENGINEERING-IMPROVEMENTS.md) for the complete
work-package decisions and versioned validation. This is not a registry release
or a clinical validation claim.

## 0.1.0 — unpublished release preparation

- Python and JavaScript/TypeScript packages expose the same local engine and
  persisted result contract, with synchronous/asynchronous Python and ESM/CJS
  JavaScript interfaces.
- Explicit runtime setup pins and verifies upstream source, dependencies and
  model hashes. Processing runs locally after setup.
- Packages include installation/API documentation, corresponding source,
  licence notices, artifact integrity checks and review/cancellation support.
- Release verification found native 3x4/12x1 candidates with unverified panel
  time origins. Those candidates are excluded from quantitative selection,
  including through peer corroboration. The tested 12x1 case now abstains;
  the 3x4 fallback remains less accurate than the tested 6x2 cases.
- Policy abstention no longer receives a misleading worker-failure code.

See VERIFICATION.md for exact payload identities, measurements and limitations.
Intermediate preparation archives all use 0.1.0 and are distinguished by hashes;
none has been published. Once published, never replace an existing version's
artifacts. Each release must record API changes and numerical/selection changes
separately, even when the public function signatures remain compatible.
